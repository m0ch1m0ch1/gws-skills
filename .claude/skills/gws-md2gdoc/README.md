# gws-md2gdoc

Markdown から Google ドキュメントを作るスキルです。手順は見出しと番号付きリストに組み直します。手順書以外の Markdown にも使えます。

## 前提条件

- [gws](https://github.com/googleworkspace/cli) をインストールし、`gws auth login` で認証している (Drive と Docs のスコープが必要)。
- Python 3。

## 使い方

```text
# input/gws-md2gdoc/ に置いた Markdown (1 つだけのとき) から作る
/gws-md2gdoc

# input/gws-md2gdoc/ のファイルを指定して作る
/gws-md2gdoc <ファイル名>

# 保存先のフォルダも指定して作る
/gws-md2gdoc <ファイル名> <フォルダの URL>
```

変換する Markdown は `input/gws-md2gdoc/` に置きます。作る前に、ファイル名・保存先・タイトル・見出しが示され、作ってよいかを聞かれます。このとき、ファイル名や保存先を変えられます。保存先を指定しなければ、マイドライブの `gws-skills/gws-md2gdoc/` に作ります (無ければ作る)。ファイル名は `yyyymmdd_<タイトル>` です。作ったあとに、ドキュメントと保存先の URL が示されます。

## 変換のしかた

入力は内容として使い、構成は読みやすさを優先して組み替えます。

| 入力 (Markdown) | Google ドキュメント |
| --- | --- |
| 先頭の YAML front matter (`---` で囲んだ部分) | 使わない |
| 最初の `#` (H1) | 先頭のタイトル (タイトルのスタイル) とファイル名 (H1 が無ければ入力のファイル名)。2 つ目以降の H1 は太字の段落 |
| H1 と最初の `##` の間の文章 | 「1. 概要」の見出しの下 |
| `##` / `###` / `####` 以下 | 見出し 1 / 2 / 3 (章番号 `2.` / `2.1.` を付ける。入力の見出しに番号が付いているもの (`## 1. 準備` など) があれば、入力の番号を活かして付けない) |
| 子の手順を持つ番号付きの項目 | 見出し (例: `4.1. <作業>します`)。番号は見出しの順に振る。末尾の「。」は取る。一度見出しにすると、後の兄弟の項目も見出しにする。見出し 3 より深くはせず、番号付きリストのままにする |
| 子を持たない番号付きの項目 | 見出しの下の番号付きリスト `1.` `2.` … (1 段だけ。コードブロックなどを挟んでも番号は続く) |
| 子に番号付きの手順を持つ箇条書きの項目 | 前置きの段落 (箇条書きだけの入れ子はそのまま入れ子の箇条書き) |
| 箇条書き | 箇条書き。番号付きリストの中の箇条書き (と箇条書きの中の番号付きの項目) は、記号 (「• 」や `1. `) を文字で付ける |
| `- [x]` / `- [ ]` | `☑` / `☐` を文字で付ける |
| `**出力例**` など、太字だけの短い段落 | 灰色のラベル (次の段落と同じページに置く) |
| コードブロック | Roboto Mono 10pt で 1 行 1 段落。コマンド (言語が `bash`・`sh`・`zsh`・`console`・`powershell` など、または `$ ` で始まる) は黒地に白文字、出力 (「出力例」「実行結果」など、出力・結果・output・result を含むラベルの直後) は白地に灰色の枠、それ以外 (YAML など) は薄い灰色の地に左の線 |
| `> **注記**` / `> [!NOTE]` などの引用 | 左線と網掛けの囲み。ラベルは線と同じ色 (注記/ヒント/Note/Tip/ラベルなし=青、重要/Important=赤、注意/警告/Warning/Caution=橙) |
| 段落の途中の改行 | つなぐ (全角の文字どうしの間には空白を入れない) |
| 表 | 表 (1 行目は太字・網掛け。罫線は薄い灰色。列幅は各列のいちばん長い文字列の長さに比例させる) |
| 区切り線 (`---`) | 使わない (見出し 1 の線で区切る) |
| `` `code` `` / `**bold**` / `*italic*` / `[text](url)` | Roboto Mono 10pt / 太字 / 斜体 / リンク |

レイアウト:

- 本文と見出しは Docs の既定のスタイルを使う。
- 本文・コードブロック・注記は左端にそろえる。リスト項目は、入れ子でも番号・記号を左端に置き、折り返した行だけ 18pt 字下げする。
- 本文と手順は行間 130%。手順の前は 16pt 空け、手順の文とその後のコマンドは同じページに置く。
- 文字は 10pt より小さくしない。
- 見出し 1 の下に細い線を引く。

制限:

- リストの中に表があると、表の前後で番号が 1 からになる。
- HTML タグ、画像、脚注などは扱わない (テキストのまま出力される)。

## 構成

```text
gws-md2gdoc/
├── SKILL.md            # 進め方
└── scripts/md2gdoc.py  # 処理の本体 (作る内容の表示・ドキュメントの作成)
```

スクリプトの使い方は `python3 -I .claude/skills/gws-md2gdoc/scripts/md2gdoc.py --help` で表示されます。
