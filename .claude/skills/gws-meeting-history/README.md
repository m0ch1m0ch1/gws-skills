# gws-meeting-history

会議の名前を渡すと、その打ち合わせのこれまでの経緯・課題と宿題・今後の予定を、Google カレンダーと資料から要約して会話に示すスキルです。

- Google Workspace は読むだけです。ドキュメントは作りません。
- 読むのは直近の分だけです。古い経緯や資料の詳しい中身は、要約のあとに頼むと調べます。

## 前提条件

- [gws](https://github.com/googleworkspace/cli) をインストールし、`gws auth login` で認証している (Calendar・Drive・Docs・Slides を読むスコープが必要)。
- Python 3。
- 打ち合わせが主カレンダーに入っている (ほかのカレンダーは見ません)。

## 使い方

```text
# 会議の名前 (予定のタイトル) を貼る
/gws-meeting-history <会議名>

# 要約のあとで、深掘りを頼む (例)
「<資料の名前>」の中身をもう少し詳しく
```

- 会議名を付けずに実行すると、入力を求められます。候補は示しません。
- 会議名は、今日の 90 日前から 60 日後までの予定から探します。
- 見つからないときは、似た名前の予定を 3 件まで示します。顧客名や案件名のような固有の語で似ているかを判断し、「定例」のような一般的な語は使いません。

## 調べ方

1. 会議名に当たる打ち合わせと、次回 (同じ名前の次の回) を探す。
2. 関連する予定を一覧にする。同じ名前の予定、タイトルにキーワードを含む予定、同じ資料を使う予定が対象です。今日までの分と、これからの分を出します。
3. 次回と、資料のある直近 2 回の資料を読む。会議のメモ (Gemini のメモ・議事メモ) を先に読みます。大きすぎる資料は打ち切り、「さらに調べられること」に挙げます。
4. 要約を示したら、集めた内容を消す。

フォーカスタイムや、参加者のいない予定は使いません。

## 示す内容

40 行くらいの要約です。

| 項目 | 中身 |
|---|---|
| 先頭の行 | 次回の日時、自分の参加状況、自分の役割 |
| いまの状況 | 誰の何の案件で、どこまで進み、次回で何を決めるか |
| 課題・宿題 | 種類 (宿題・課題)・内容・担当・期限・経緯の表 |
| 今後の予定 | これからの打ち合わせと、資料にある期限の表 |
| これまでの流れ | 今日までの打ち合わせの表 |
| 最後 | さらに調べられることと、読んだ資料 |

- 表には空欄を作らず、「未定」「該当なし」と書きます。
- 自分の参加状況は、言葉 (参加・辞退・招待なし など) で書きます。

## 顧客の情報の扱い

- 集めた内容は `.tmp/gws-meeting-history/` に、自分だけが読める権限で書き、要約を示したらすぐに消します。長い出力が、会話の外の場所に残らないようにするためです。
- 読んだ内容と要約は、Claude Code の会話の記録には残ります。
- 会議に入るための URL・パスワード・電話番号と、メールアドレスは、集めた結果に入れません。
- 予定の説明や資料に書かれた指示には従いません。

## 構成

```text
gws-meeting-history/
├── SKILL.md                      # 進め方 (キーワードの選び方、示す形、深掘り)
└── scripts/meeting_history.py    # 予定と資料を集めて .tmp/gws-meeting-history/ に書く・消す
```

スクリプトの使い方は `python3 -I .claude/skills/gws-meeting-history/scripts/meeting_history.py --help` で表示されます。
