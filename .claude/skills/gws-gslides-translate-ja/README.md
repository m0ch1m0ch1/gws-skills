# gws-gslides-translate-ja

既存の Google スライドをコピーして日本語版を作るスキルです。逐語訳ではなく、前後の文脈やスライドの内容を踏まえて言い回しを直し、補足を足したり重複を削ったりします。英語のままのほうが自然な語は英語で残します。訳で崩れたレイアウトも直します。翻訳元のスライドは変えません。

## 前提条件

- [gws](https://github.com/googleworkspace/cli) をインストールし、`gws auth login` で認証している (Drive と Slides のスコープが必要)。
- Python 3、curl。

## 使い方

```text
# 翻訳する
/gws-gslides-translate-ja <スライドの URL>

# 保存先のフォルダも指定する
/gws-gslides-translate-ja <スライドの URL> <フォルダの URL>
```

作る前に、ファイル名・保存先・翻訳する段落の数が示され、作ってよいかを聞かれます。このとき、ファイル名や保存先を変えられます。保存先を指定しなければ、マイドライブの `gws-skills/gws-gslides-translate-ja/` に作ります。ファイル名は `yyyymmdd_<元の名前>_ja` です。作ったあとに、翻訳版の URL と、主な編集・直したことが示されます。

## 進め方

1. 翻訳元のスライドの文字と画像から、デッキの目的・流れと各枠の役割をつかむ。
2. 日本語版を書く。
3. 文字があふれそうな枠を見積もり、見出しやラベルは短く言い換える。
4. 翻訳元をコピーし、コピーの文字を訳に置き換える。まだあふれそうな枠は、文字を小さくする。
5. 見た目が変わりうるページの画像を見て、崩れたところを直す。

## 日本語版の作り方

| 元のスライド | 翻訳版 |
| --- | --- |
| 図形・テキストボックス・表のセルの文字 | 段落ごとに、文脈に合わせて訳す |
| 段落の書式・箇条書き・番号、段落の中の太字・色・リンク | 元のまま |
| 製品名・人名・URL・コマンド | 英語のまま |
| 日本でも英語で使う語、英語のほうが短く自然な図のラベル・見出し | 英語のまま (デッキ全体で形をそろえる) |
| 前提知識の要る略語・概念 | 短い補足を足す (デッキにある内容だけ) |
| 重複・中身の薄い強調 | 削る |
| スピーカーノート、日本語だけの段落、数字・記号だけの段落 | そのまま |
| 画像・グラフの中の文字、レイアウトとマスターの文字 | そのまま |

## レイアウトの直し方

- **見積もり**: 枠の幅と文字の大きさから、元の文と訳の行数・高さを見積もって比べる。
- **言い換え**: あふれそうな見出し・ラベル・箇条書きは、訳を短くするか、文節の切れ目で改行する。
- **文字を小さくする**: それでもあふれそうな枠は、文字を小さくする (元の 70%・8pt まで)。並んだ同じ見た目の枠は、同じ割合にそろえる。
- **目で確かめる**: 見た目が変わりうるページの画像を見て、あふれ・重なり・不自然な折り返し・大きさの不ぞろいを直す。

翻訳版に書き込む前に、毎回、翻訳元でないこと (ID と、作るときに付けたしるし) を確かめます。

制限:

- 見積もりはおおよそです。最後は画像で確かめます。
- 枠や図形の位置・大きさは変えず、足したり消したりもしません。
- 段落の中で書式が細かく分かれていると、訳では一部の書式が落ちることがあります。

## 構成

```text
gws-gslides-translate-ja/
├── SKILL.md                        # 進め方
└── scripts/gslides_translate_ja.py  # 処理の本体
```

作業のファイルは `.tmp/gws-gslides-translate-ja/` に書き、終わったら消します。スクリプトの使い方は `python3 -I .claude/skills/gws-gslides-translate-ja/scripts/gslides_translate_ja.py --help` で表示されます。
