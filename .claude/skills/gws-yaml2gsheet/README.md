# gws-yaml2gsheet

YAML から Google スプレッドシートのパラメータシートを作るスキルです。フォルダ 1 つから 1 つのスプレッドシートを作り、先頭に目次を置いて、中の YAML 1 つを 1 つのシートにします。

## 前提条件

- [gws](https://github.com/googleworkspace/cli) をインストールし、`gws auth login` で認証している (Drive と Sheets のスコープが必要)。
- Python 3。

## 使い方

```text
# input/gws-yaml2gsheet/ に置いたフォルダ (1 つだけのとき) から作る
/gws-yaml2gsheet

# input/gws-yaml2gsheet/ のフォルダを指定して作る
/gws-yaml2gsheet <フォルダ名>

# 保存先のフォルダも指定して作る
/gws-yaml2gsheet <フォルダ名> <保存先のフォルダの URL>
```

YAML (`.yaml` / `.yml`) をフォルダに入れて、そのフォルダを `input/gws-yaml2gsheet/` に置きます (例: `input/gws-yaml2gsheet/<フォルダ名>/01-<名前>.yaml`)。フォルダの直下の YAML を名前の順にシートにします (サブフォルダの中は使いません)。作る前に、入力・ファイル名・保存先・シート (パラメータの数・リソースの見出しかいちばん外側のキー) が示され、作ってよいかを聞かれます。このとき、ファイル名・保存先を変えられます。保存先を指定しなければ、マイドライブの `gws-skills/gws-yaml2gsheet/` に作ります (無ければ作る)。ファイル名は `yyyymmdd_<タイトル>_パラメータシート` で、タイトルはフォルダ名です (変えられます)。作ったあとに、スプレッドシートと保存先の URL が示されます。

## 目次

先頭のシート「目次」に、次のものを置きます。

- タイトル (ファイル名の `<タイトル>`) と、作成日・シート・リソース・パラメータの数
- シート / リソース / パラメータ数 の表。リソース (ドキュメントの見出し) は、そのシートのその見出しの行へのリンク。リソースの見出しが無いシートは、いちばん外側のキーを並べてシートの先頭へのリンクにする

## シートの形

目次の後ろに、YAML 1 つが 1 つのシートになります (シート名は拡張子を除いたファイル名)。Kubernetes のマニフェストのように `---` で区切った複数のドキュメントを含むファイルも、1 つのシートにします。キーは `キー:`、リストの要素は `[1]` `[2]` … と書き、階層ごとの細い列に置いて縦に並べます。

```text
| No | 項目                          | 値      | 備考       |
| <kind> / <metadata.name>                                    |   ← リソースの見出し
| 1  | apiVersion:                   | <値>    |            |
|    | metadata:                     |         |            |   ← 子を持つキー
| 2  |   | name:                     | <値>    | <コメント> |
|    | spec:                         |         |            |
|    |   | <キー>:                   |         |            |
|    |   |   | [1]                   |         |            |   ← リストの要素
| 3  |   |   |   | <キー>:           | <値>    |            |
| 4  |   |   |   | <キー>:           | <値>    |            |
                                                                ← リソースの間は空ける
| <kind> / <metadata.name>                                    |
```

| 入力 (YAML) | シート |
| --- | --- |
| キー | `キー:`。項目の列のうち、その階層の列に書く |
| 子を持つキー | 値の無い太字の行 (行全体が青みのある灰色の地。1 階層目は濃く、それより下は淡く)。子は 1 つ右の列に置く |
| 値のあるキー (パラメータ) | 白地の行。値のセルだけ薄い黄色の地にする |
| マッピングのリスト | 要素ごとに `[1]` `[2]` … の親の行を入れ、要素のキーはその 1 つ右の列に並べる |
| 値のリスト | `[1]` `[2]` … の行に値を書く |
| 値 | 書いたとおりの文字列 (引用符は取る。`0755` や `yes` を数や真偽に変えない)。Roboto Mono で表示し、書式は書式なしテキスト。URL に見えてもリンクの色にしない |
| 値の無いキー / `{}` / `[]` | 空 / `{}` / `[]` |
| `\|` / `>` の複数行の文字列 | 改行を含む 1 つのセル (末尾の改行は取る) |
| `[a, b]` / `{k: v}` | ブロックで書いたときと同じように展開する |
| キーの直前の行のコメントと、行末のコメント | 備考 |
| `---` で区切ったドキュメント | ドキュメントごとに見出しの行を入れる。見出しは `<kind> / <metadata.name>`。kind が無ければ、複数のときは「ドキュメント N」、1 つなら見出しを入れない |
| 最初のキーより前のコメント (ファイルの説明・注記)、空の行より前のコメント、ドキュメントの最後のコメント | 使わない |

レイアウト:

- No は値のある行 (パラメータ) にだけ、シートの中で通しで振る (淡い灰色)。
- 表の見出しの行は淡い地で、下の線だけを濃くする。スクロールしても残す。
- リソースの見出しは濃い地で、kind を白の太字、名前を淡い色にする。
- 備考の文字は値より淡くする。
- 罫線は淡い灰色。枠線 (グリッド線) は隠す。セルには左右に余白を取り、上下中央にそろえる。1 行に収まる行は高さを少し広げ、収まらない行は折り返す。
- 項目は階層ごとの細い列に分け、キーは右の空いた列にはみ出させる (セルの中で字下げしない)。項目の列の間には縦の線を引かない。
- 項目の列は、最後の列だけをいちばん長いキーに合わせ、ほかは細くする。値と備考の列幅は、いちばん長い文字列に合わせる。

扱えない書き方 (`[NG]` になる):

- アンカー (`&`)・エイリアス (`*`)・マージ (`<<: *x`)・タグ (`!<タグ>`)
- `?` のキー、字下げのタブ、いちばん外側がマッピングかリストでないドキュメント
- 複数行にまたがる引用符の文字列、重なったキー

## 構成

```text
gws-yaml2gsheet/
├── SKILL.md                 # 進め方
└── scripts/yaml2gsheet.py   # 処理の本体 (YAML の読み込み・作る内容の表示・スプレッドシートの作成)
```

スクリプトの使い方は `python3 -I .claude/skills/gws-yaml2gsheet/scripts/yaml2gsheet.py --help` で表示されます。
